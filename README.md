# AI-Powered Data Analyst Assistant

An AI-powered application that helps users analyze
CSV and Excel datasets using natural language.

## Technologies
- Python
- Pandas
- NumPy
- Streamlit
- OpenAI API

## Features
- CSV and Excel file uploads
- Dataset preview
- Missing value detection
- Statistical summaries
- AI-powered data analysis

Stage 1: Streamlit application and file upload completed.
